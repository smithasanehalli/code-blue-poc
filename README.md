# code-blue-poc

POC repository for code-blue

## Getting started

```bash
npm install
npm run dev
```

Open the URL Vite prints. The sign-in screen is pre-filled with demo values; select
**Fake Sign in** to reach the Patient List. No real authentication takes place.

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build to `dist/`
- `npm run lint` – run ESLint

## Specs

Feature specifications live in `specs/` and follow the SDD workflow in `.specify/`.
